Supplementary Materials for Manuscript SJ-0826-0026

This repository contains supporting computational materials associated with Manuscript ID SJ-0826-0026. The files document molecular simulations and related analyses of H2, CO2, CH4, and He in water-containing mineral systems involving illite, montmorillonite, calcite, and quartz.

Contents

The `Supplementary data.rar` archive is organized as follows:

| Directory | Description |
| --- | --- |
| `01_GROMACS_Inputs/` | GROMACS structures, topologies, and simulation parameter files (`.gro`, `.top`, `.mdp`) for 37 model setups across the S, T, and W series. |
| `02_Force_Fields/` | Mineral and molecular force-field files (`.itp`) used to define the simulated systems. |
| `03_CP2K_DFT/` | CP2K input files, output logs, and initial structures (`.inp`, `.out`, `.xyz`) for 56 calculation cases, including clean mineral surfaces, reference gas molecules, and gas–surface configurations. |
| `04_Analysis_Scripts/` | 13 Python scripts for analysis of spatial distributions, near-surface enrichment, diffusion, gas–water radial distribution functions, surface contacts, residence times, adsorption energies, and force-field parameter sensitivity. |
| `05_FigureData/` | Origin project files (`.opju`) corresponding to Figures 2–9. |

Using the files

GROMACS and CP2K input files can be examined using the corresponding simulation packages, while the Origin projects contain the figure-source materials. The Python scripts are organized by analysis topic within `04_Analysis_Scripts/`.

These materials are provided as supporting data for Manuscript SJ-0826-0026. Please refer to the manuscript for the scientific methodology, interpretation, and associated figures.
